## Runtime blockers and source pointers

1. **Codex approval protocol:** `router/src/runner.ts` handles command, file-change and permissions approval methods but not `mcpServer/elicitation/request`. The traced real request asks “Allow the hagency MCP server to run tool \"create_task\"?” and has an empty-object form schema. It receives no client response and the turn waits. `codex-unhandled-elicitation.json` is the sanitized receipt; full trace is private. An independent real app-server probe using the same Codex model completed in about 3.1 seconds, ruling out basic authentication/provider unavailability for this attempt. The client must handle the server request and return an appropriate decision; see the [official app-server protocol](https://learn.chatgpt.com/docs/app-server). This test did not auto-approve it.
2. **Claude launch and model:** `backend-v2.js` `claudeThreadSessionArgs()` requires home `.mcp.json`, while on-demand provisioning does not prepare it. The same launcher only passes `descriptor.modelOverride` to `--model`, ignoring `runtimeProfile.primary.model` when no override exists. The missing config was reproduced; model omission is source-confirmed. The actual Claude model used in this run was not independently traced, so the stored Fable label is not proof of Fable execution.
3. **MCP tool contract:** `lib/mcp-server-core.js` around its `api()` helper allows the scoped router task-creation path but rejects the exposed legacy messaging/task-transition paths. Actual agent responses provide the exact refusals. The agent's first statement that *every* MCP call was blocked was overbroad: the later `create_task` test succeeded. Only the specific refused tools are reported as failures here.
4. **Cold setup:** wizard callback resume state and verification rendering, absent allocation/owner inputs, unused-preset capability filtering, registration-token intake and bridge room mapping prevent a fresh operator from reaching task execution without out-of-band recovery.
5. **Client release gate:** native Agent Operations remains unavailable; plain Matrix chat passing does not satisfy that separate capability.
