# 群聊与 Agent 私聊

项目方先申请 Agent，由 HAFleet 批准分配。之后使用以下两种方式。

## 项目房间

大家正常发言即可。HAFleet 保存文字、发言人和时间，普通聊天不会
启动 Agent。需要它处理时，选中实际的 Agent 账号进行 @，例如：

> @Agent 总结刚才大家的意见，列出分歧和待办。

Agent 会读取这个房间中尚未处理的讨论，包括其他人的发言及 Agent
公开回复，再结合本次指令作答。首次启用会补读 Matrix 允许访问的
历史；后续按每个 Agent 自己的处理位置读取。较长讨论会分段读取。
只有成功回复后才更新位置，处理期间的新发言会留给下一次 @。

在项目房间的任务线程里继续交代工作，也需要 @。

## 私聊

在 Robrix2 打开你和已分配 Agent 的私聊，直接发消息，不需要 @。
它会结合本私聊的上下文继续回答；上一轮完成或 HAFleet 重启都不会
清空这段对话。明文和加密私聊均可使用，现有房间的加密设置保持原样。

新私聊会自动关联该 Agent 的现有项目分配，沿用项目的审批人。
你需要仍是该项目成员，且该 Agent 有唯一有效的分配。私聊中只有
你和 Agent；加入其他人后，它会暂停按私聊处理。

涉及需要授权的操作时，仍由原项目审批人在既有私人审批房间决定。
普通聊天、读取本次讨论和日常任务状态维护不会产生额外操作审批。
