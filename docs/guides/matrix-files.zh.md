# 在房间和私聊中交换文件

Hagency Agent 现在可以接收 Matrix 附件，也可以把生成的文件作为真正的附件发回来。

## 房间里发文件给 Agent

1. 在 Robrix2 打开已经有 Agent 加入的房间，使用附件按钮上传文件。
2. 上传完成后，发一条消息并选中 Agent 的 `@` 提及，例如：
   `@edison 读取刚上传的 CSV，计算数量合计，把结果保存为 TXT 文件发回来。`
3. Agent 从当前房间读取附件，在原来的 thread 回复结果和可下载的文件。

多人房间只上传文件不会唤醒 Agent。之后可以指定一个或多个已加入的 Agent
处理该文件。普通聊天和附件内容不会成为系统指令或操作审批。

## 私聊发文件

在 Agent 的 DM 中上传附件，再说明需要它做什么，不需要 `@`。
只发送文件时，Agent 会收到文件；要求不明确时它可以询问处理方式。
加密 DM 的文件和消息都会使用 Matrix 加密。

## 让 Agent 发回文件

可以直接说：“把报告作为 Markdown 文件发回来”“把结果保存为 CSV 附件”，
或者“把生成的图片发到这里”。收到的是可下载的文件，不是 Hagency 机器上的本地路径。

单个文件上限 20 MiB。Agent 可以发送当前工作目录内的普通文件，目标固定为当前
房间、thread 或 DM。不能通过该工具任意指定其他人的房间。文件过大、已失效或
解密失败会报告原因；尚在排队的发送不能被说成已送达。文件内容的解析取决于
Agent 可用的工具，传输本身不要求特定文档格式。

私聊增加其他成员后继续遵守既有隐私隔离：新成员和新加入的 Agent 不会因此得到
之前的私聊附件。
